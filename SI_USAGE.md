# Super Intelligence (SI) Usage Disclosure — SOLARA

SOLARA was developed with assistance from Super Intelligence (SI) tools to accelerate software development, problem-solving and documentation.

### Tools Used

- **ChatGPT:** Project brainstorming, architectural guidance, debugging assistance, technical research and documentation.
- **OpenCode with GLM 5.3 Flash:** AI-assisted user interface development and implementation.
- **OpenCode with DeepSeek V4.1 Flash:** AI-assisted backend development, scientific data integration, debugging and testing.
- **OpenAI Codex CLI:** AI-assisted coding, implementation and code refinement.
- **Google Antigravity CLI:** AI-assisted coding, logo design and UI design.


### Areas of SI Assistance

SI tools were used to assist with:
- Application architecture and technical planning.
- Frontend and interface development.
- Backend implementation and API integration.
- Scientific data integration and processing logic.
- AI Mission Copilot development.
- Debugging, code review and documentation.
- Logo designing

All SI-assisted implementation was subject to human review, testing and refinement by the development team.

### Scientific Data and Attribution

SOLARA uses scientific datasets obtained from external sources, including NASA and USGS resources. These datasets retain their original source attribution and are not represented as AI-generated.

AI assistance in code development does not constitute the generation of the underlying scientific observations.

### Human Oversight

The team remains responsible for the project's implementation, scientific integrity, testing and final functionality. SI tools were used as development assistants, not as substitutes for scientific verification or team decision-making.
